# Privacy

- Search terms, selected major category, hierarchy filter, business descriptions, and chosen classification codes are processed in the browser.
- The URL is not changed to contain search or classification state.
- Up to eight public classifications are stored in that browser's `localStorage` and can be removed at any time.
- No cookie banner, advertising tracker, external analytics script, fingerprint, account, or authentication system is used.
- Anonymous product telemetry stores only a random browser UUID hash, allowlisted action name, QA flag, and time for 35 days.
- Telemetry has no columns for search text, classification code, classification name, business details, IP address, or User-Agent.
