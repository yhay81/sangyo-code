# Stack

- Cloudflare Workers and custom domain: request handling and public delivery
- Hono with JSX: server-rendered pages, metadata, sitemap, health, telemetry endpoint
- Vite+: formatting, linting, type checking, testing, and build
- Static JSON assets: verified e-Stat classification data and client-side search
- D1: minimal anonymous, allowlisted, 35-day telemetry
- Browser `localStorage`: optional bundle of at most eight public classification records

Authentication and a server-side search database are not required for this scope.
